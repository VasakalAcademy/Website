# Vasakal Academy Website

Official repository for the Vasakal Academy website.

## Overview
Vasakal Academy is an educational institution empowering students with focused coaching, V 30 programs, and academic excellence.

## Project Structure
- `website/`: React frontend application built with Vite, Tailwind CSS, and Lucide icons.

## Getting Started
To run the website locally:
```bash
cd website
npm install
npm run dev
```

To build for production:
```bash
cd website
npm run build
```
